## 一、从你带回来的日志里读出来的三件事

### 1️⃣ 好消息：前面全通了，一个都没漏

```
[0.017] 第1步 窗口已显示、界面已就绪（主线程，全程不碰文件）
[0.099] 界面 1/4 开始建字体（CreateFontIndirectW ×5）
[0.303] 界面 4/4 完整界面绘制完成
[1.229] 第3步 网络栈已启动
[1.233] ──────── 自检结束，开始连接 ────────
```

启动、建窗口、建字体、画完整界面、开网络栈 —— **全部一次通过**。
上一版「闪退」的那个毛病，根因（日志模块自己崩）确实修掉了。

### 2️⃣ 坏消息：卡在第一关 —— ADB 设备

```
[1.261] ADB 设备 ADB1: 打不开（错误 55）
[19.581] ADB 设备已打开: ADB1:
[19.595]    XX   ADB 设备打开 + 认证 + 端口转发  ← ADB 认证失败（错误 -1）
```

这段有两个关键点，我一开始都读错了，重新推了一遍才看明白：

**① 错误 55 的意思是「驱动根本没加载」。**
车机里的 `adb_driver.dll`（百度随车机出厂预装的 ADB 主机驱动）只有在
**手机上露出 ADB 接口**时才会被系统加载。没有这个接口，连 "ADB1:" 这个名字
都不存在 —— 所以报 55。**这就是「手机上没开 USB 调试」最直接的表现。**

**② 「错误 -1」不是手机的错，是程序自己太急。**
19.581 打开成功，19.595 就报失败 —— **中间只过了 14 毫秒**。
一次真正的协议握手不可能 14 毫秒就失败（程序给了 8 秒）。
真相是：车机的 ADB 驱动是**非阻塞**的，程序刚把握手包发出去就去读应答，
驱动返回「此刻还没数据」，**而程序把这个当成了「设备坏了」直接放弃。**

> 也就是说：哪怕你手机上什么都设置对了，程序也永远会在 14 毫秒后
> 自己认输。**这是必须修的真 bug，不是环境问题。**

### 3️⃣ 还有一个自己给自己添堵的地方

```
[19.581] ADB 设备已打开: ADB1:      ← 打开成功
[19.595] （握手失败，程序把设备关了）
[21.614] ADB 设备 ADB1: 打不开（错误 110）
[23.647] ADB 设备 ADB1: 打不开（错误 110）
   …… 连续 18 次，一直持续到 56 秒 ……
[58.576] ADB 设备已打开: ADB1:      ← 终于又缓过来了
```

**这个驱动的「关闭」是脏的**：关一次之后要几十秒才缓得过来。
而程序每隔 2 秒就给它来一轮「开 → 失败 → 关」，等于一直把它按在坏状态里。

## 二、这一版改了什么

| # | 改动 | 为什么 |
|---|---|---|
| 1 | **读设备改成在超时预算内轮询**，只有「设备真的拔了」才算失败 | 修掉那个 14 毫秒自杀的 bug |
| 2 | **设备句柄黏住复用**，不再每 2 秒开关一次 | 不再自己把 ADB 驱动按进坏状态 |
| 3 | **失败原因分成四句不同的话**：手机没应答 / 设备读写失败 / 授权被拒 / 握手失败 | 以前全塌成「认证失败（错误 -1）」，现场分不清该修哪边 |
| 4 | **握手每一步都进日志**（发了什么、收到什么、命令字多少） | 下一次一趟车就能定位到具体哪一包 |
| 5 | **每轮开头打印车机的 USB/ADB 注册表状态** | 直接看出 ADB 驱动到底有没有注册（= 手机有没有露出 ADB 接口） |
| 6 | **每轮开头打印上一轮的字节数/错误次数统计** | 「写不进去」和「读不出来」是两码事，靠数字一眼分开 |
| 7 | 屏幕上的「已等待 N 秒」改成真实计时 | 以前按「次数×2 秒」估算，现在每轮可能要等 8 秒，估的不准 |

## 三、你现在要做的（重点在手机，不在车机）

👉 **看同目录下的《手机端设置清单.md》，照着一步一步做。**

最要紧的两条，一分钟就能核对：

1. **手机上「开发者选项 → USB 调试」必须是打开的。**
   不开，车机里那个 ADB 驱动永远不会加载（就是日志里的「错误 55」）。
2. **「USB 用途」别选「连接车辆」，选「传输文件」。**
   选「连接车辆」会让手机切到厂商专用的互联模式，把 ADB 接口顶掉 ——
   名字最像，反而最不该选。

做对了的标志：手机通知栏出现 **「USB 调试已连接」**。

## 四、车机屏幕上现在会说什么（新版）

新版把失败原因分开了，屏幕上直接告诉你该修哪边：

| 屏幕显示 | 意思 | 修哪边 |
|---|---|---|
| `打不开任何 ADB 设备`（错误 55） | 驱动没加载 = **手机没开 USB 调试** | 手机 |
| `ADB 设备读写失败` | 设备认到了、管道不通 | 换个车机 USB 口 / 换线 |
| `手机没应答` | 包发出去了，手机一个字没回 = **「允许」的框没点** | 手机 |
| `手机拒绝了 ADB 授权` | 框点了「取消」 | 手机（撤销授权后重来） |
| `正在启动车载系统` | ✅ **最难的一关过去了** | 继续等画面 |
