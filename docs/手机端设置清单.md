# 手机上要怎么设置（一次讲清）

> 这份是给「车机上显示连接失败」时看的。
> 结论先说：**车机能不能连上，九成取决于手机上这两个开关。**
> 车机那头的程序已经修好了，剩下的基本都在手机这边。

---

## 一、先把原理讲明白（30 秒，看懂这一段就不会瞎试）

车机里自带一个叫 `adb_driver.dll` 的官方驱动（百度随这台车机出厂预装的），
它只认一种 USB 接口：

```
接口 class = 255 (0xFF) ，subclass = 66 (0x42) ，protocol = 1
```

**这三种数字凑在一起的那个接口，在安卓世界里只有一个含义：ADB（USB 调试）。**

也就是说：

> ⚠️ **手机上不开「USB 调试」，这个接口根本不会出现，
> 车机就永远看不到手机。**

反过来，只要这个接口出现了，车机就能认到手机 —— 这一步和你在手机上装不装
任何 App 都没关系（这正是我们想要的效果：手机端零安装）。

---

## 二、手机上照着做，一步都别跳

### 第 1 步：打开开发者选项

| 品牌 | 路径 |
|---|---|
| vivo / iQOO | 设置 → 系统管理 → 关于手机 → 连点「软件版本号」7 次 |
| OPPO / 一加 | 设置 → 关于本机 → 版本信息 → 连点「版本号」7 次 |
| 小米 / 红米 | 设置 → 我的设备 → 全部参数 → 连点「MIUI 版本」7 次 |
| 华为 / 荣耀 | 设置 → 关于手机 → 连点「版本号」7 次 |

### 第 2 步：把「USB 调试」打开 ⭐ 最关键

设置 → 系统管理（或「更多设置」）→ **开发者选项** →

- ✅ **USB 调试** —— 必须打开
- ✅ 如果下面还有一条 **「USB 调试（安全设置）」**（vivo/OPPO 常见），**也打开**
- 顺手把 **「默认 USB 配置」** 设成 **「传输文件 (MTP)」**

### 第 3 步：用**数据线**把手机插到车机的 USB 口

⚠️ 注意三点：

1. **必须是能传数据的线。** 很多线只能充电，插上去手机只会充电，
   车机什么都看不到。
2. **插车机上原来给手机互联用的那个 USB 口。** 如果车机有两个 USB 口，
   优先插标着「手机 / CarLife / 互联」的那个；实在分不出来就两个都试一遍。
3. **程序要先用 U 盘启动起来，再插线。** 车机上的程序会自己等 120 秒，
   你不用抢时间。

### 第 4 步：手机上会弹一个框

插上线之后，手机上应该弹出来：

> **「是否允许 USB 调试？」**
> 计算机 RSA 密钥指纹：xx:xx:xx...
> ☐ 一律允许使用这台计算机进行调试
> 【取消】 【允许】

👉 **勾上「一律允许」，然后点「允许」。**

如果框没弹出来：
- 把线拔了重插一次；
- 或者到 开发者选项 → **「撤销 USB 调试授权」** 点一下，再拔插一次；
- 还不行就把「USB 调试」关掉再打开一次。

### 第 5 步：确认「USB 用途」不要选「连接车辆」⭐ 第二个关键

手机顶部下拉通知栏，会有一条「正在通过 USB 为设备充电」之类的通知，
点开它 → 选 **「传输文件 / MTP」**。

> ❌ **不要选「连接车辆」。**
> 这个名字听起来最对，但它会让手机切到「车机互联」那套专用的 USB 模式，
> 把 ADB 接口顶掉 —— 车机反而就看不见手机了。
> 我们走的是通用 ADB 这条路，不是手机厂商那套互联通道。

选对了的标志：通知栏出现 **「USB 调试已连接」**（或「正在通过 USB 调试」）。

## 三、车机屏幕上会怎么反馈（照着对号入座）

车机上的程序一直在重试，你在手机上改设置，它几秒内就会跟着变。

| 车机屏幕上显示 | 含义 | 该怎么办 |
|---|---|---|
| `打不开任何 ADB 设备`（错误 55） | 车机的 ADB 驱动根本没加载 = **手机上没开 USB 调试**，或线只能充电 | 回第 2 / 第 3 步 |
| `ADB 设备读写失败` | 驱动认到设备了，但管道不通 | 换一个车机 USB 口 / 换线，再拔插一次 |
| `手机没应答` | 包发出去了，手机一个字没回 = **「允许 USB 调试」的框没点** | 回第 4 步 |
| `手机拒绝了 ADB 授权` | 框点了「取消」，或没勾「一律允许」 | 撤销授权后重来 |
| `正在启动车载系统` | ✅ **成功穿过了最难的一关** | 继续等，看能不能出画面 |

> 屏幕上看到前四种也别急着退出 —— 把手机设置改好，等 8 秒它会自己重来一轮。

## 四、万一带回来的日志怎么给

不管成没成，都把这两个文件拷到 U 盘带回来：

| 文件 | 在哪 |
|---|---|
| `carlife-log.txt` | 车机内部存储根目录下的 `iNAND` 文件夹里（也可能在 `Residentflash2` / `SDMEM`） |
| `carlife-check.txt` | 同上 |

日志里现在每一行都写清楚了「走到哪一步、为什么停下」，
连每一次握手发了什么、收到什么都记着，拿回来我一眼就能看出卡在哪。

---

## 五、为什么这事值得这么较真

因为这台车机上的 `adb_driver.dll` 是**百度原厂**的 USB 主机端驱动，
而百度自己的车机程序 `CECarLife.exe` 用的就是同一个设备名 `ADB1:`。
换句话说：

> **这条路是这台车机出厂时就在用的那条路，不是我们硬凑出来的。**

它唯一的要求就是「手机上把 ADB 接口露出来」——也就是上面那两个开关。
把开关配对，后面的事情（拉手机端 App、搬画面、回传触摸）代码里都已经写好了。
